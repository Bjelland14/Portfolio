# Portfolio

My personal portfolio website, showcasing my newest projects from my Frontend Development studies at Noroff.

**Live site:** https://lloydbjellandportfolio.netlify.app/

## About

I'm a Frontend Development student at Noroff, finishing in December 2026, and I'm working towards becoming a fullstack developer. I build with React, TypeScript and REST APIs, and I'm learning C# and .NET.

## Features

- Responsive layout for desktop and mobile
- Hand-drawn `<B/>` logo with a drawing animation on page load
- Projects rendered from a JavaScript array
- Download CV button
- Accessibility: skip link, visible keyboard focus, alt text and reduced motion support

## Built With

- HTML
- CSS
- JavaScript
- Google Fonts (Bricolage Grotesque and Atkinson Hyperlegible)
- Netlify

## Projects

Recipe app built in an agency-style team for a fictional client. I was scrum master and responsible for SEO and analytics.

Responsive auction platform built with TypeScript, Vite and Bootstrap, with login, listings, bidding and profiles.

## Running Locally

1. Clone the repository:

```
   git clone https://github.com/Bjelland14/Portfolio
```

2. Open the project folder in VS Code.
3. Open `index.html` with Live Server, or directly in your browser.
